A personal portfolio website for **M Hasini Reddy**, a B.Tech Computer Science and Engineering student at Amrita Vishwa Vidyapeetham, working across AI/ML, NLP, federated learning and full-stack development.

## Sections

| Section | What it shows |
|---|---|
| Home | Introduction, social links and animated hero |
| About | Professional summary, approach, strengths beyond code and quick-info cards |
| Education | B.Tech and higher secondary details |
| Skills | Categories of languages, frameworks, tools and core CS concepts |
| Projects | One featured project and a filterable grid with problem, solution and tech stack |
